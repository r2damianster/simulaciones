# Editor APA 7 — Cinta de Herramientas

Referencia sobre la interfaz editor tipo Word (ribbon) para la formación de manuscritos según APA 7 en fases secuenciales.

## Estructura del Editor

Simula una barra de herramientas (ribbon) de editor de textos profesional con grupos de funciones:

### Grupo Tipografía
- **Fuente:** Times New Roman, Arial (solo 2 opciones permitidas en APA 7).
- **Tamaño:** 12 pt obligatorio.
- **Estilos:** Negrita (B), cursiva (I), subrayado (U).

### Grupo Párrafo
- **Alineación:** Izquierda (predeterminada), centrada, justificada.
- **Espaciado:** 1.5, 2.0 (doble, requerido en APA 7), 2.5.
- **Sangría:** Primera línea 0.5", francesa (para referencias), ninguna.

### Grupo Márgenes
- **Superior, inferior, izquierda, derecha:** 1" (2.54 cm) cada uno.

### Grupo Herramientas APA
- **Portada:** Toggle para mostrar/ocultar.
- **Encabezado:** Insertar nombre autor + número de página.
- **Referencias:** Modo bibliografía (automático vs. manual).
- **Salto de página:** Insertar quiebre manual entre secciones.

## Flujo de Uso

Las herramientas se desbloquean secuencialmente por sección del manuscrito:
1. **Fase 1:** Portada (tipografía, título, autor).
2. **Fase 2:** Encabezados y espaciado de cuerpo.
3. **Fase 3:** Márgenes y sangría de referencias.
4. **Fase 4:** Verificación final (todas las herramientas disponibles).

## Guía de clase — preguntas para conversar

Panel flotante dentro de la simulación (botón de comentarios, arriba a la derecha). Al terminar la simulación aparece un aviso discreto que abre la pestaña «Después».

### Español
**Antes**
1. ¿Qué elementos de un documento académico esperan encontrar bien formateados antes de leer el contenido?
2. ¿Qué herramientas de un procesador de texto usan hoy para dar formato, y cuáles ignoran por costumbre?
3. ¿Por qué dar formato con estilos es mejor que hacerlo a mano párrafo por párrafo?

**Durante**
1. ¿Qué herramienta de la cinta usaste para resolver cada requisito y por qué esa y no otra?
2. ¿Qué fase te resultó más difícil y qué regla de APA explica esa dificultad?
3. ¿Qué ocurriría si aplicaras el formato manualmente en un documento de 40 páginas?
4. ¿Qué error de formato se vuelve invisible a simple vista y solo aparece al revisar con atención?

**Después**
1. ¿Qué hábitos de trabajo con el procesador de texto cambiarían a partir de esta práctica?
2. ¿Cuándo el formato ayuda a la lectura y cuándo la entorpece?
3. ¿Qué criterios aplicarían para revisar el formato de un trabajo ajeno de manera respetuosa y útil?
4. Elaboren una lista de verificación de 8 puntos para entregar un trabajo en APA 7. ¿Cuál punto se olvida con más frecuencia?

### English
**Before**
1. Which elements of an academic document do you expect to find well formatted before reading the content?
2. Which word-processor tools do you use today to format, and which do you ignore out of habit?
3. Why is formatting with styles better than doing it by hand, paragraph by paragraph?

**During**
1. Which ribbon tool did you use to meet each requirement, and why that one and not another?
2. Which phase was hardest and which APA rule explains that difficulty?
3. What would happen if you applied the format manually in a 40-page document?
4. Which formatting error is invisible at a glance and only appears under careful review?

**After**
1. Which word-processing habits would you change after this practice?
2. When does format help reading and when does it get in the way?
3. Which criteria would you apply to review someone else's formatting in a respectful and useful way?
4. Build an 8-point checklist for submitting a paper in APA 7. Which item is forgotten most often?
